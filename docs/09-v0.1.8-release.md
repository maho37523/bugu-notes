# Android v0.1.8 release

## Delivered

- Unified workspace search for notes, conversations, and messages, with type and note tag/folder filters.
- Per-session drafts and immutable request snapshots for cited notes, quote text, text attachments, and images; retries reuse the saved context.
- Streamlined project, settings, and sidebar entry points.
- Markdown file import into the selected project/folder, bounded to 2 MiB and read off the main thread.
- Full local backup export and preview-before-replace restore, including database records, drafts, and attachments. API settings are excluded.
- Common supported Markdown subset shared by editor and preview, plus editor find/replace.
