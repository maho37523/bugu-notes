# 02 · DeepSeek Android 产品定义与交互逻辑

> 版本：v0.1　|　日期：2026-11-03　|　状态：待评审
> 配套：[ChatGPT 移动端拆解](01-chatgpt-mobile-benchmark.md) · [原型实现方案](03-prototype-tech-plan.md)

## 0. 一句话

**一个不用选模式的 AI 助理：你说，它就懂；它做，你看得见；做完，你带得走。**

## 1. 产品定位

### 1.1 为谁做

| 人群 | 典型场景 | 最在意什么 |
| --- | --- | --- |
| 学生 / 研究者 | 读论文、查资料、解释概念、写文献综述 | 准确、引用、能追问 |
| 职场知识工作者 | 写方案、读报告、整理会议、做调研 | 省时间、结果能直接用 |
| 开发者 / 创作者 | 读代码、查文档、写文案、做原型 | 快、可编辑、可导出 |

首版聚焦**中文手机用户**，不追求全人群覆盖。

### 1.2 核心场景

1. **随手问**：一个概念、一段报错、一个决定，30 秒内得到可用答案。
2. **查清楚**：需要最新信息或多方对比时，自动联网、给出来源。
3. **读东西**：拍一张图、传一份 PDF，直接问，答案能指回原文。
4. **写东西**：从提纲到成稿，在对话里改，在画布里定稿。
5. **持续跟**：一个项目、一个话题、一份日报，交给“项目”和“任务”。

### 1.3 差异化

- **零模式焦虑**：不要求用户理解“快速/专家/识图/联网”的区别，系统自动判断，并把判断结果说人话。
- **中文与推理**：DeepSeek 的强项，体现在长文、逻辑、代码、中文语境，而不是“什么都能聊”。
- **过程透明**：思考、搜索、研究过程可见、可打断、可接管。
- **轻**：不塞插件市场、不塞工作台、不塞社区；一个对话解决 90% 的事。

### 1.4 不做什么

- 不做图像/视频生成。
- 不做浏览器自动化、云端电脑、Work 类长任务执行。
- 不做插件市场、连接器生态。
- 不做多人实时协作。
- 不做健康、金融、购物等垂直业务。
- 不做 CarPlay/车机。

这些不是“永远不做”，而是**首版原型不投入**；其中部分会在 P2 留入口。

## 2. 设计原则

1. **一个输入框，零模式焦虑**：所有输入从一个框进入；模式是系统的判断，不是用户的前置选择。
2. **答案先到，过程后置**：先让用户看到答案；思考、搜索、来源折叠在答案上方，需要时展开。
3. **自动可解释，手动可接管**：自动路由要显示“为什么”；用户随时能改，不用重新输入。
4. **长任务离开页面也能活**：研究、任务、语音都能后台运行，用通知回收。
5. **记忆与项目是留存的地基**：第二次打开的理由，不是“语音好玩”，而是“它记得我”“它懂这个项目”。
6. **每个结果都能被带走**：复制、长图、链接、PDF、Markdown，至少有一种顺手的导出。

## 3. 功能范围

### P0：没有就不像“完整产品”

| 模块 | 能力 | 验收标准 |
| --- | --- | --- |
| 对话 | 流式、停止、重试、重新生成、多版本、编辑消息 | 首字 < 1.5s；停止后内容保留；版本可切换 |
| 输入 | 文字、图片、文件、听写、语音通话入口、工具面板 | 任意输入 3 步内完成；上传有进度与失败重试 |
| 搜索 | 自动判断、过程可见、行内引用、来源下钻 | 每个引用可点开；无结果有明确说明 |
| 视觉 | 拍照/相册、多图、OCR、追问 | 图片可放大、可提取文字、可继续问 |
| 文件 | PDF/Office/图片、解析状态、页码引用 | 答案能指到页/工作表；失败可重试 |
| 语音 | 全屏通话、打断、字幕、转写回聊天 | 打断 < 500ms；结束后有完整转写 |
| 记忆 | 自动提取、可见可改、按对话关闭 | 用户能查到“它记得什么、从哪来” |
| 项目 | 资料、指令、项目内对话、项目级记忆 | 项目内新对话自动带上下文 |
| 历史 | 搜索、置顶、归档、重命名、删除 | 1 万条对话下搜索 < 1s |
| 分享 | 长图、链接、PDF/Markdown | 分享内容不含记忆来源 |
| 设置 | 账号、通用、对话、语音、通知、数据 | 关键开关 2 层内到达 |
| 异常 | 离线、超时、限流、内容拒绝 | 每种都有明确文案与下一步 |

### P1：决定“比别人好用”

- 深度研究：澄清 → 计划 → 执行 → 报告 → 导出。
- 定时任务：自然语言创建、推送、运行历史。
- 画布：文档/代码/网页产物编辑与预览。
- 后台语音、锁屏继续。
- Android 集成：分享目标、桌面小组件、快捷设置磁贴。
- 分支对话、临时对话。
- 自定义指令。

### P2：先留入口

- 多账号切换、锁定对话。
- 项目共享/协作。
- 连接器（Drive/Notion/MCP）。
- 主动式每日简报。
- 图片生成（无模型能力，仅占位）。
- 学习模式（引导式辅导 / 测验），学生场景的差异化候选。
- 自定义助手（角色 / 知识包）。
- 桌面/平板深度适配。

## 4. 对象模型

```
User
 ├── Conversation 1..N ── Message 1..N ── ContentBlock
 │        │                    ├── Citation
 │        │                    ├── Attachment
 │        │                    └── Artifact
 │        ├── Project 0..1
 │        └── ResearchRun 0..1
 ├── Project 1..N ── Source 1..N
 ├── Memory 1..N ── MemorySource
 └── Task 1..N ── TaskRun 1..N
```

| 对象 | 关键字段 | 说明 |
| --- | --- | --- |
| Conversation | id, title, project_id, pinned, archived, locked, temporary, mode_override, created_at, updated_at | 对话是原子对象；语音、研究、任务结果都落到对话 |
| Message | id, role, status, content_blocks, model, reasoning, created_at | status: sending/thinking/streaming/done/stopped/failed/moderated |
| ContentBlock | type, payload | text / reasoning / tool_call / citation / image / file / artifact / task_card / research_card / memory_used |
| Attachment | id, name, mime, size, local_uri, remote_file_id, parse_status, page_count | 上传后先本地占位，再替换为远端 |
| Project | id, name, icon, instructions, memory_mode, created_at | 上下文容器，不是文件夹 |
| Source | id, project_id, type, name, file_id, url, parse_status | 项目资料 |
| Memory | id, type, content, confidence, source_refs, created_at | type: 身份/偏好/目标/项目事实/关系 |
| Task | id, title, prompt, schedule, timezone, status, next_run_at, notify | 定时/周期任务 |
| TaskRun | id, task_id, status, result_conversation_id, started_at, error | 每次执行 |
| ResearchRun | id, conversation_id, plan, status, progress, report, sources | 深度研究 |
| Artifact | id, message_id, type, title, content, version | 画布产物 |

## 5. 信息架构

### 5.1 导航

底部 4 个 Tab，进入对话详情后隐藏，回到列表时恢复：

```
├── 对话（默认）
│   ├── 首页：问候 + 建议 + 输入框 + 最近对话
│   ├── 对话详情
│   └── 抽屉：搜索 / 新对话 / 项目 / 任务 / 记忆 / 设置 / 全部历史
├── 项目
│   ├── 项目列表
│   └── 项目详情：资料 / 对话 / 指令 / 设置
├── 任务
│   ├── 任务列表：进行中 / 已暂停 / 已完成
│   └── 任务详情：计划 / 历史 / 编辑
└── 我的
    ├── 账号与套餐
    ├── 记忆
    ├── 设置
    └── 帮助与关于
```

> 备选：ChatGPT 式抽屉（无底部 Tab）。优点是更沉浸；缺点是项目/任务发现性差。**原型默认 4 Tab，便于评审时快速到达每个能力。**

### 5.2 路由

| 路由 | 说明 |
| --- | --- |
| `/` | 对话首页 |
| `/chat/{id}` | 对话详情 |
| `/project/{id}` | 项目详情 |
| `/task/{id}` | 任务详情 |
| `/memory` | 记忆管理 |
| `/settings/...` | 设置子页 |
| `/share/{token}` | 分享落地页（Web） |

- 新建对话：如果当前对话为空，复用；否则新建。
- 返回：全屏页 → 对话；对话 → 首页；首页再返回 → 退出。
- 深链：推送点开直达对话/任务结果；分享链接直达只读页。
- 状态恢复：进程被杀后回到原对话与滚动位置。

## 6. 全局交互框架

> 结构示意见 [核心界面线框](../design/reference/core-screens.png)；本文用文字描述状态与规则，线框不代表最终视觉。

### 6.1 首页

```
┌─────────────────────────────┐
│ (头像)      DeepSeek     (新对话) │
│                             │
│  晚上好，Cris                 │
│  今天想聊点什么？              │
│                             │
│  [建议 1]  [建议 2]           │
│  [建议 3]  [建议 4]           │
│                             │
│  最近对话                     │
│  ...                        │
│                             │
│ ┌─────────────────────────┐ │
│ │ +  输入消息…   🎙 〰️  ↑ │ │
│ └─────────────────────────┘ │
│  对话   项目   任务   我的     │
└─────────────────────────────┘
```

- 问候随时段变化；建议卡结合时间、最近项目、热点，最多 4 个，可关闭。
- 输入框不自动弹键盘；点击后展开。
- 最近对话显示 3 条，更多进抽屉。
- 顶部左侧头像打开抽屉；右侧“新对话”在任何页面可用。

### 6.2 输入框解剖

```
[项目: 毕业论文 ×] [📎 报告.pdf ×] [✨ 自动 ▾]
┌─────────────────────────────────────┐
│ + │ 输入消息…              │ 🎙 │ 〰️ │ ↑ │
└─────────────────────────────────────┘
```

| 控件 | 点击 | 长按 | 状态 |
| --- | --- | --- | --- |
| `+` | 打开工具面板 | 快速选最近照片 | 有附件时显示数量角标 |
| 输入框 | 键盘 | 粘贴长文自动转附件 | 多行自增高，最大 6 行 |
| `🎙` | 开始听写 | 提示“点右侧通话” | 录音中变为波形 + 取消/确认 |
| `〰️` | 发起语音通话 | — | 通话中全局悬浮条 |
| `↑` | 发送 | — | 空内容禁用；流式中变“停止” |

**工具面板**（点 `+`）：

```
拍照   相册   文件
深度研究   画布   项目资料
```

- 当前模型不支持的能力置灰并说明原因（例如未配置图像生成）。
- “项目资料”只在项目内出现。

### 6.3 能力面板（自动模式）

点输入框上方的 `✨ 自动 ▾`：

```
思考深度     [自动]  [快速]  [深入]
联网         [自动]  [开启]  [关闭]
回答风格     [简洁]  [标准]  [详细]
─────────────────────────────
当前：自动（Flash · 按需深度思考 · 按需联网）
[重置为自动]
```

规则：

- 默认全自动；用户手动改任一项后，该对话进入“手动”状态，顶部 chip 显示 `✨ 深入 · 联网`。
- 手动设置只影响当前对话，新对话回到自动。
- “深入”提示预计耗时；“快速”隐藏思考过程（仍可展开）。
- “联网-关闭”时，若问题明显需要最新信息，回答前提示“未联网，可能不含最新信息”，并给“开启联网重答”按钮。

### 6.4 发送后的状态机

```
draft → sending → queued → thinking → streaming → done
                                  ├→ stopped
                                  ├→ failed
                                  └→ moderated
```

| 状态 | UI | 可执行 |
| --- | --- | --- |
| sending | 用户气泡右侧出现时钟 | 取消发送（2s 内） |
| queued | “排队中…” | 取消 |
| thinking | 助手占位 + 计时 + “正在思考” | 停止 |
| streaming | 逐字输出 + 光标 | 停止、回到底部 |
| done | 操作栏出现 | 复制/重生成/分享/朗读 |
| stopped | “已停止” + “继续生成” | 继续、重生成 |
| failed | 错误卡 + 重试 | 重试、复制错误码 |
| moderated | 拒绝卡（非错误样式） | 修改提问、申诉 |

**首字目标**：P50 < 800ms，P95 < 1.5s；超过 1.5s 必须出现“正在思考”而非空白。

### 6.5 消息操作

长按助手消息：

```
复制   选择文字   分享   朗读
重新生成   从此分支   反馈（👍/👎）
```

- 重新生成：不覆盖旧回答，顶部出现 `‹ 1/2 ›`。
- 编辑用户消息：底部弹出编辑器；保存后确认“将重新生成后续回答”，旧分支保留。
- 反馈：点踩后展开原因（不准确/太啰嗦/不安全/其他），可附文字。
- 朗读：调用 TTS，播放时消息底部出现进度条与暂停。

### 6.6 手势、返回与键盘

- 侧滑返回：全屏页 → 对话；对话 → 首页；首页 → 退到后台。
- 下拉：对话顶部下拉可“搜索本对话”（P1）。
- 双击消息：复制（可在设置关闭）。
- 键盘：输入框随键盘上移；底部 Tab 隐藏；发送后键盘保持，方便连续追问。
- 长按输入框：粘贴/清空。
- 滚动：仅在贴底时自动跟随；用户上滑后显示“回到底部”胶囊。

### 6.7 主题与排版

- 默认跟随系统深浅色；提供“纸感米白”与“深空黑”两套品牌色。
- 正文字号 16sp，行高 1.6；代码 13sp 等宽；公式居中。
- 圆角 20dp；气泡最大宽度 88%；用户气泡右对齐、品牌色浅底；助手不画气泡，直接排版（更像阅读）。
- 动效克制：只在“思考/说话/搜索”三个状态使用循环动画；支持“减少动态效果”。

### 6.8 从对话升级为任务：三条路径怎么触发

这是整个产品最关键的“分流逻辑”。原则：**升级不换页面，只在原对话里加一张卡；用户拒绝一次，短期内不再打扰。**

| 用户信号 | 系统动作 | 不做什么 |
| --- | --- | --- |
| “帮我调研 / 对比 / 综述 / 选型 / 写份报告”，且问题明显多步 | 输入时在输入框上方出现 `深度研究` 提示；发送后也可在回答末尾建议 | 不自动开始长任务 |
| “每天 / 每周 / 到点 / 提醒我 / 帮我盯着” | 直接解析为任务确认卡，停在确认前 | 不静默创建定时任务 |
| 连续上传多份资料、反复问同一主题 | 建议“建一个项目，把资料放进去” | 不强制迁移已有对话 |
| 只是问一个事实、要一个解释 | 直接回答，不出现任何升级提示 | 不为了推功能而打断 |
| 用户点“不用了” | 记录偏好，7 天内不再建议同类升级 | 不反复弹窗 |

升级后的关系：

- 深度研究 = 这条对话里的一个“研究卡”，展开是全屏报告；不是新对话。
- 定时任务 = 这条对话派生出的“任务”，结果写回同一条对话；也可在任务 Tab 管理。
- 项目 = 把这条对话“移进去”，继承项目资料与指令；对话本身不复制。

## 7. 关键流程

### 7.1 首次启动与登录

**目标**：30 秒内发出第一条消息；不拿权限、不拿偏好挡住用户。

1. 启动页 ≤ 600ms，直接进欢迎页。
2. 欢迎页：一句价值主张 + “开始使用” + “已有账号登录” + 小字“先逛逛（游客）”。
3. 登录：手机号 + 验证码；协议默认未勾选；验证码 60s 倒计时；错误就地提示。
4. 首次进入（可跳过）：
   - “怎么称呼你？”
   - “你主要用我做什么？”（学习/工作/创作/编程/随便聊聊）
   - “喜欢什么样的回答？”（先结论/详细推导/轻松一点）
   - 这三项生成初始自定义指令，后续可在设置修改。
5. 首页：不自动弹键盘；建议卡基于第 4 步选择。
6. 权限：全部延迟到使用时申请；拒绝后给出“去设置”与“改用文字”的替代。
7. 数据说明：首次进入用一张底部卡片说明“对话默认用于改进服务，可在设置关闭”，只出现一次。

**状态**：

- 游客：可对话，历史存本地；登录时提示“合并本地对话 / 仅保留云端”。
- 验证码错误：保留输入，倒计时不清零。
- 网络失败：显示“网络不可用，可先以游客体验”。
- 协议未勾选：按钮禁用 + 轻提示，不弹窗。

### 7.2 新建对话与首轮

1. 点“新对话”或从首页输入 → 进入空白对话。
2. 空白对话保留建议卡（3 个），但不显示问候语，避免重复。
3. 用户输入 → 发送。
4. 首轮回答完成后，自动生成标题（3-6 字），可长按重命名。
5. 首轮后出现“继续追问”建议（2-3 个），点击填入输入框而非直接发送。

**空状态**：网络正常但无历史时，展示 3 个示例问题；有历史时展示最近对话。

### 7.3 回答、思考与多版本

**回答的解剖**（从上到下）：

```
[活动条] 已搜索 3 个关键词 · 阅读 8 个来源        〉
[思考条] 思考了 12 秒                            〉
[正文]   ……带行内引用 [1][2]……
[卡片]   图片 / 表格 / 画布产物 / 任务卡
[来源]   8 个来源                               〉
[记忆]   使用了 2 条记忆                         〉
[操作]   复制 · 重新生成 · 分享 · 朗读 · 👍 👎
```

**思考过程**：

- 默认折叠为一行“思考了 12 秒”；流式中显示“正在思考 6s”。
- 点击展开，灰色等宽排版；顶部提示“这是模型的思考过程，可能不准确”。
- 回答开始后出现“跳至回答”。
- 手动选“快速”时默认不展示思考条；用户仍可在消息菜单打开。

**流式规则**：

- 40ms 批量刷新，避免逐 token 重组整页。
- 代码块在闭合前用纯文本渲染，闭合后高亮，避免闪烁。
- 公式在段落结束后渲染，避免半截公式。
- 用户上滑后停止自动滚动，显示“回到底部 ↓”胶囊。
- 切后台继续生成；通知栏显示“正在生成…”，完成后可点开。

**多版本**：

- 重新生成后，回答顶部 `‹ 1/2 ›`；左右切换即时显示，不重新请求。
- 编辑用户消息后，旧分支保留；对话顶部出现分支图标，可切换分支（P1 完整树，P0 只保留最近一条旧分支）。

**停止与继续**：

- 停止后保留已生成内容，底部显示“已停止 · 继续生成”。
- 继续生成从断点续写；若服务端不支持，重新生成并标注“重新生成”。

### 7.4 联网搜索

**触发**：

| 信号 | 例子 | 行为 |
| --- | --- | --- |
| 时间敏感 | “今天/最新/本周/价格/股价/新闻” | 自动联网 |
| 事实核验 | “是真的吗/有没有这回事” | 自动联网 |
| 用户手动 | 能力面板开启 | 强制联网 |
| 模型判断 | 需要外部知识 | 工具调用时联网 |
| 项目资料足够 | 项目内有相关文件 | 优先资料，不联网 |

**过程**：

1. 发送后出现活动条：“正在搜索「2026 国产大模型 API 价格」…”。
2. 展示 1-3 个 query chip；可展开看每个 query 的结果数。
3. 搜索完成：“已阅读 8 个来源”，来源 favicon 横排。
4. 回答流式输出，句末带 `[1]` 引用。
5. 回答结束展示“来源”区：标题、域名、日期、摘要；权威源标记“权威”。

**来源下钻**：

- 点引用 → 底部抽屉：来源列表 + 当前来源摘要 + “打开原网页”。
- 点“打开原网页” → 内置阅读器（WebView + 阅读模式）；顶部显示域名与安全提示。
- 阅读器内可“引用这段”“复制链接”“在浏览器打开”。

**冲突与失败**：

- 多来源冲突：回答中插入“来源存在分歧”提示卡，列出各方说法。
- 无结果：明确说“没有搜到可靠来源”，给出改用模型知识回答的选项。
- 超时：活动条变红“搜索超时”，可重试或直接回答。
- 限流：提示“搜索太频繁，10 秒后重试”，不阻塞普通对话。

**设置**：默认联网（自动/始终/从不）、搜索语言（跟随系统/中文/英文）、安全搜索（P2）。

### 7.5 图片理解

**入口**：`+` → 拍照 / 相册；或从系统分享图片进来。

**拍照页**：

- 取景框、快门、相册缩略图、翻转、闪光灯。
- “扫描”模式：边缘检测、自动裁切、多页连拍、合成 PDF（P1）。
- 拍完进入预览：裁切/旋转/重拍/添加更多（最多 9 张）。

**发送后**：

1. 图片网格显示在用户消息中；上传进度覆盖在缩略图上。
2. 活动条：“正在识别 3 张图片…”。
3. 回答：描述、提取文字、回答针对图片的问题。
4. 快捷动作：`提取文字` `翻译` `解释图表` `问这张图`。

**查看**：

- 点图片 → 全屏：双指缩放、左右滑、保存、分享、识别文字可选中复制。
- 图片上的文字块可点选，弹出“复制/翻译/针对这句提问”。

**边界**：

- 大图压缩到长边 2048px，EXIF 去除定位。
- HEIC 转 JPEG；透明 PNG 保留。
- 纯文字模型不支持视觉时，自动路由到视觉模型；若都不可用，提示“当前模型不支持图片”。
- 权限拒绝：引导设置 + “从文件选择”。

### 7.6 文件问答

**入口**：`+` → 文件；系统文档选择器；支持多选（最多 10 个）。

**支持格式**：PDF、DOCX、XLSX、PPTX、TXT、MD、CSV、图片。单文件 ≤ 50MB。

**上传与解析**：

1. 选择后立即上传，消息内出现文件卡：图标、文件名、大小、进度、取消。
2. 解析状态：“解析中 2/3” → “已就绪” / “失败”。
3. 失败卡：“无法读取，可能是扫描版或加密文件”，提供“重试/改用图片”。
4. 解析完成前发送：提示“文件还在解析，解析完会自动继续”。

**回答与引用**：

- 答案引用格式：`（第 12 页）`、`（Sheet2!B3）`、`（第 4 张幻灯片）`。
- 点引用 → 文件预览定位到对应页/单元格，高亮原文。
- 文件卡点开 → 预览：PDF 分页、DOCX 转 HTML、XLSX 表格、PPTX 缩略图。
- 预览内可“针对这段提问”，把选中文本作为引用发回对话。

**上下文**：

- 输入框上方显示“上下文 12%”细条；超过 80% 提示“对话较长，建议新建对话或使用项目”。
- 超出上下文时，自动摘要旧消息并提示“已压缩早期对话”。

**边界**：加密 PDF、扫描件 OCR、超大表格抽样、重复文件、删除附件后引用失效。

### 7.7 语音通话

**两个入口，必须区分**：

| 入口 | 图标 | 行为 | 适用 |
| --- | --- | --- | --- |
| 听写 | 🎙 | 录音 → 转文字进输入框，可编辑后发送 | 嘈杂、需要精确措辞、长问题 |
| 通话 | 〰️ | 全屏实时对话，自动断句、自动朗读 | 走路、做饭、开车（停车时） |

**首版形态**：半双工——自动断句、自动请求、自动播放；播放时点按光球或“打断”按钮立即停止并回到聆听。**持续收音 + 开口即打断**（需要回声消除）放在 P1，不阻塞首版。

**通话页**：

```
┌─────────────────────────┐
│   (收起)          (更多) │
│                         │
│        ◉ 光球            │
│      正在听…             │
│                         │
│  你：帮我对比一下…        │
│  AI：好的，我先说结论…    │
│                         │
│  [字幕] [静音] [扬声器] [挂断] │
└─────────────────────────┘
```

**状态机**：

| 状态 | 触发 | 视觉 | 文案 | 操作 |
| --- | --- | --- | --- | --- |
| 连接中 | 点通话 | 光球呼吸 | 正在连接… | 取消 |
| 聆听 | 连接成功 | 光球随麦克风起伏 | 我在听 | 静音/挂断 |
| 思考 | 用户停顿 800ms | 光球旋转 | 让我想想… | 挂断 |
| 说话 | 首包音频 | 光球随 TTS 起伏 | 正在回答 | 打断/静音 |
| 被打断 | 用户开口 | 光球转回聆听 | 你说 | — |
| 静音 | 点静音 | 光球变灰 | 已静音 | 取消静音 |
| 后台 | 切后台/锁屏 | 通知栏“通话中” | — | 回到通话/挂断 |
| 结束 | 挂断/超时 | 收起 | 已结束 | 查看转写 |

**打断（barge-in）**：

- 首版：点按“打断” → 300ms 内停止 TTS、清空播放缓冲、保留已说文字的半截，回到聆听。
- P1：持续收音，检测到用户开口即打断；需要 AEC 与噪声抑制，误触发时可在设置调“抗噪强度”。
- 打断后向服务端发送 interrupt；开始新一轮 ASR，不重复上一轮。

**背景通话**：

- 使用 `microphone` 类型前台服务 + 常驻通知（静音/挂断/回到通话）。
- 锁屏继续；切到其他 App 继续；连续 30 秒无人声 → “你还在吗？”；再 30 秒结束。
- 通话结束自动生成转写卡：时长、轮次、全文、继续追问。

**音色**：贝壳（活泼）、白浪（坚定）、海星（甜美）、暗潮（低沉）；设置内可试听。默认跟随账号语言。

**失败**：

- 麦克风权限拒绝 → 引导设置 + 改用听写。
- 网络中断 → “通话需要网络”，保留已转写内容，可重连。
- TTS 失败 → 降级为文字 + 字幕，不中断会话。
- ASR 空结果 → “没听清，再说一次”，不重复上一轮。

### 7.8 深度研究

**先分清搜索与研究**：

| | 联网搜索 | 深度研究 |
| --- | --- | --- |
| 适合 | 一个事实、最新动态、快速核对 | 多源对比、综述、选型、写报告 |
| 耗时 | 5-30 秒 | 8-20 分钟 |
| 产出 | 一段带引用的回答 | 结构化报告 + 来源 + 过程 |
| 触发 | 自动 | 用户确认后 |

**入口**：

- `+` → 深度研究。
- 用户输入明显需要多步调研（“帮我调研/对比/综述/选型”）→ 回答后出现建议条“要我做一份深度研究吗？”。
- 输入 `/research`（可选）。

**流程**：

```
意图 → 澄清（可选）→ 研究计划 → 执行 → 报告
```

1. **澄清**：最多 3 个问题，用 chips 选择，不弹表单。
   - 例：“聚焦哪一年？”“需要覆盖哪些厂商？”“报告给谁看？”
2. **计划卡**：
   ```
   研究计划
   2026 国产大模型 API 价格与能力对比
   1. 市场格局与主要玩家
   2. 价格结构（输入/输出/缓存）
   3. 能力对比（上下文/工具/多模态）
   4. 适用场景与选型建议
   来源：公开网络，优先官网/论文/权威媒体
   预计 8-12 分钟 · 约 25 个来源
   [调整计划] [开始研究]
   ```
3. **执行**：全屏进度页，时间线：
   - 拆解问题 ✓
   - 搜索 24 个来源 ✓
   - 阅读 18 篇 ✓
   - 交叉验证（进行中）
   - 撰写报告
   可离开页面；通知栏显示进度；完成后推送。
4. **报告**：
   - 标题、摘要、目录、正文、行内引用。
   - 三个 Tab：报告 / 来源 / 过程。
   - 末尾“局限性”与“进一步研究建议”。
5. **导出**：PDF、Markdown、复制全文；分享链接（P1）。

**中断与调整**：

- 执行中“暂停并调整” → 输入补充要求 → 继续，不重头开始。
- 取消 → 保留已完成部分，标注“未完成”。
- 失败 → 保留中间结果 + “继续研究”。

**限制**：同时 1 个；单次 10-20 分钟；最多 30 个来源；每日次数按套餐。

### 7.9 记忆

**记什么**：

| 类型 | 例子 | 写入方式 |
| --- | --- | --- |
| 身份 | “我是产品经理，在做 AI 硬件” | 用户明说 / 高置信推断 |
| 偏好 | “先给结论，别太长” | 用户明说 / 多次行为 |
| 目标 | “12 月前完成 MVP” | 用户明说 |
| 项目事实 | “项目面向东南亚市场” | 项目内明说 |
| 关系 | “我的猫叫豆包” | 用户明说 |

**不记**：密码、证件、银行卡、精确住址、健康诊断、他人隐私、一次性任务细节。

**写入**：

- 用户说“记住…” → 立即写入，回答后显示“已记住”卡片（可撤销/编辑）。
- 模型判断值得记 → 不打断，回答下方显示 `记住了 1 件事 · 查看`；点开可编辑/删除。
- 每条记忆带来源对话链接与时间；冲突时以新为准，旧记忆标记“已过期”。

**读取**：

- 回答若使用记忆，底部显示 `使用了 2 条记忆 〉`；点开列出具体条目与来源。
- 设置“记忆使用”开关；关闭后不读不写。
- 临时对话：不读不写；开始前可选“使用已有记忆”（默认否）。

**管理**：

- 我的 → 记忆：按类型分组、搜索、编辑、删除、清空。
- 每条可“不要再提”；不删除源对话，只抑制引用。
- “导出记忆”为 Markdown；删除 30 天内彻底清除。

### 7.11 定时任务

**创建（自然语言优先）**：

用户：“每天早上 8 点给我一份 AI 行业简报，重点看模型发布和融资。”

→ 解析为确认卡：

```
定时任务
名称：AI 行业早报
时间：每天 08:00（Asia/Shanghai）
内容：汇总过去 24 小时 AI 行业重要新闻，按重要性排序，附来源
执行：联网搜索 · 自动选择模型
通知：推送 + 写入对话
下次：明天 08:00

```

- 有歧义只问 1 个问题（“周末也要吗？”），不弹多步表单。
- 时间必须显示时区；跨时区旅行不改变任务时区（可改）。
- 创建后请求通知权限；拒绝则仅写入对话。

**列表**：

- 进行中 / 已暂停 / 已完成。
- 每项：标题、下次运行、上次结果、开关。
- 左滑暂停，右滑删除（带撤销）。

**执行**：

- 到点后台运行；完成后推送“你的「AI 行业早报」已生成”，展开可看摘要。
- 点通知 → 打开结果对话；结果以卡片形式出现在任务对话中。
- 失败：自动重试 1 次；仍失败则推送“任务失败，点击查看”，连续 3 次失败自动暂停。

**限制**：最多 5 个进行中；最小间隔 1 小时；单次执行超时 10 分钟。

## 8. 状态与异常

| 场景 | 空 | 加载 | 失败 | 离线 | 限流 |
| --- | --- | --- | --- | --- | --- |
| 对话列表 | 示例问题 + 新建 | 骨架屏 3 条 | 重试 + 本地缓存 | 显示缓存，顶部条 | — |
| 发送消息 | 输入框禁用发送 | 排队/思考 | 错误卡 + 重试 | 草稿保留，提示 | 重置时间 + 升级 |
| 流式回答 | — | 逐字 + 光标 | 保留半截 + 重试 | 断线重连 3 次 | 暂停生成 |
| 搜索 | — | query chip + 来源数 | 超时/无结果说明 | 提示需联网 | 10s 后重试 |
| 文件上传 | 选择器 | 进度 + 解析状态 | 失败原因 + 重试 | 排队，恢复后继续 | — |
| 语音通话 | 引导文案 | 连接中 | 降级文字/重连 | 明确提示 | 剩余时长提示 |
| 深度研究 | 示例主题 | 阶段时间线 | 保留中间结果 | 暂停，恢复后继续 | 每日次数 |
| 定时任务 | 示例任务 | 创建中 | 创建失败原因 | 本地待同步 | 上限提示 |
| 记忆 | 说明 + 示例 | 加载 | 重试 | 本地缓存 | — |
| 项目 | 引导添加资料 | 骨架屏 | 重试 | 缓存 | — |

**全局异常**：

- 登录过期：静默刷新；失败则弹“重新登录”，草稿不丢。
- 进程被杀：重进恢复到原对话；未完成回答标记“已中断”，可重试。
- 长对话：超过 80% 上下文提示；超过上限自动摘要，保留最近 20 轮原文。
- 内容拒绝：独立卡片，说明原因，给“修改提问”而非“重试”。
- 服务降级：搜索/研究不可用时，普通对话仍可用，并在入口标注“维护中”。

## 10. 技术映射

| 能力 | DeepSeek 侧 | 说明 |
| --- | --- | --- |
| 对话 | `POST /chat/completions`，`stream=true` | SSE；OpenAI 兼容 |
| 思考 | `thinking:{type:"enabled"}` + `reasoning_effort` | 流中返回思考内容；默认开启 |
| 视觉 | `deepseek-flash` + `image_url`/base64/`file_id` | `deepseek-v4-pro` 不支持视觉，需路由 |
| 搜索 | `/v1/tools/search`、`/v1/tools/fetch` | 也可由模型 tool call 触发；按次计费 |
| 文件 | Files API 上传换 `file_id` | 解析/预览建议放服务端 |
| 上下文 | 1M token，最大输出 384K | 长对话需摘要与分段 |
| 语音 | **公开 API 文档未见实时语音接口** | 需第三方 ASR/TTS 或半双工；这是最大外部依赖 |
| 记忆 | 无专用 API | 服务端 LLM 抽取 + 检索；原型可本地 Room + 关键词 |
| 任务 | 无调度 API | 生产用服务端 cron + 推送；原型 WorkManager |
| 分享 | 无 | 自建快照页 + 短链 |
| 图像生成 | 无 | 不做 |

**需要一个小后端**：文件解析、语音中转、任务调度、分享快照、记忆存储。纯客户端只能做 Demo，做不了完整体验。

## 11. 原型策略

### 两种保真度

| 方案 | 做什么 | 适合 | 成本 |
| --- | --- | --- | --- |
| A. 可点击高保真 | 全部页面 + 假数据 + 模拟流式/语音 | 投资/管理层评审、交互定稿 | 低 |
| B. 可运行 MVP | 核心链路接真 API，高级功能 Mock | 研发验证、种子用户试用 | 中 |

**建议：B 为主，A 为辅**。核心链路（对话、搜索、图片、文件、语音半双工）接真；深度研究、任务、画布先做“可演示的 Mock”，避免范围失控。

### 里程碑（假设 1 Android + 1 后端 + 1 设计）

| 阶段 | 时长 | 产出 |
| --- | --- | --- |
| P0 骨架 | 3 天 | 设计系统、导航、假数据、Mock 流式 |
| P1 对话核心 | 1 周 | 真流式、思考、停止/重试、历史、Markdown |
| P2 多模态 | 1 周 | 图片、文件、搜索引用 |
| P3 语音与上下文 | 1 周 | 半双工语音、记忆、项目 |
| P4 高级能力 | 1 周 | 深度研究、任务、画布（Mock 优先） |
| P5 打磨 | 3 天 | 异常态、分享、无障碍、演示脚本 |

### 演示脚本（评审时按此走）

1. 问“今天 AI 圈有什么大事？”→ 看自动联网、过程、引用。
2. 传一份 PDF → 问“第 3 页的核心结论是什么？”→ 点引用跳页。
3. 拍一张图表 → 问“这组数据说明什么？”→ 提取文字 + 解释。
4. 发起语音 → 中途打断 → 结束看转写。
5. 说“记住我偏好先给结论” → 新对话 → 看“使用了 1 条记忆”。
6. 建项目 → 加资料 + 指令 → 在项目内提问。
7. 说“帮我调研…”→ 改计划 → 跑完看报告。
8. 说“每天 8 点给我简报” → 确认卡 → 看任务列表。

## 12. 指标

- **北极星**：每周“有效对话”数（有追问或导出/分享的对话）。
- **激活**：首次启动 → 首条消息 ≤ 60s；首日 3 条消息。
- **留存**：D1 / D7 / D30；记忆开启率、项目创建率。
- **质量**：首字延迟 P95、回答完成率、重试率、点踩率、引用打开率。
- **多模态**：图片/文件消息占比、语音通话时长与完成率。
- **任务**：研究完成率、报告导出率、定时任务 7 日存活率。
- **信任**：记忆查看/删除率、临时对话使用率、分享率。
