# v0.1.2 实现记录

> 版本：0.1.2（versionCode 4）　|　状态：已构建 APK　|　范围：Android 原生

## 1. 本版决策

- 一个笔记/聊天只属于一个项目
- 项目记忆默认 `project_only`，不引用其他项目
- 直接采用单栏混合编辑器（非分屏）
- 暂不做电脑 DSH 连接和远端构建
- 附件 P0：图片 / PDF / 文本
- 手动命名版本 + 自动保存工作副本；垃圾桶/归档保留 30 天

## 2. 数据层

Room 升到 **version 3**，迁移链 `1 → 2 → 3`，不丢旧笔记：

- 新增 `projects`、`chat_sessions`、`chat_messages`、`memories`、`attachments`
- `notes.projectId`、`chat_sessions.archivedAt`
- `chat_messages.quoteText`
- `note_revisions` 增加 `name / version / kind`
- 默认项目 `inbox`（收件箱），旧笔记/会话自动归入
- 聊天从内存迁到 Room；消息包含 reasoning、来源引用、附件名、quote

## 3. 已实现

### 项目
- 项目列表、新建、删除（对象回收到收件箱）
- 笔记/聊天归属单项目
- 笔记编辑器可切换项目
- 对话顶栏显示项目名，可点开项目列表
- 记忆按项目隔离，默认仅项目

### 笔记编辑器
- 单栏混合编辑：非活动块渲染 Markdown，点按块进入源码编辑
- 粗体/斜体/标题/列表/引用/代码/链接/双链工具栏
- 成对符号删除（`[]`、`()`、`{}`、`<>`；`[]()` 链接组合）
- 撤销/重做（60 步）
- 500ms 自动保存工作副本
- 手动命名版本、每 10 分钟自动检查点、版本列表、恢复（恢复生成新版本）
- 分类下拉内直接「新建分类」并选中
- 复制全文、导出 `.md`
- 双链在混合预览中可点击；链接笔记/反向链接在文档中可见
- **笔记内 AI 已删除**；改为「引用到对话」把笔记内容交给对话

### 对话与上下文
- 对话持久化，重启恢复会话
- `@` 引用笔记；`[[` 自动补全插入双链并附带笔记上下文
- 消息中的 `[[笔记]]` 可点击打开笔记
- AI 消息操作「引用这段」→ composer quote chip → 下一轮显式引用
- 消息「记住这条」写入当前项目记忆
- 复制整段对话；归档当前会话 / 归档本项目全部会话
- 已归档会话页：批量恢复、批量永久删除（二次确认）
- 附件：相册图片（视觉 base64）、PDF 文本提取（PDFBox）、文本/Markdown 读取；附件内容进入上下文

### 记忆
- 项目记忆列表，增删、启用/停用
- 对话发送时把启用记忆作为 system 上下文
- 默认 project-only，无全局记忆串项目

### 生命周期
- 笔记删除进垃圾桶；垃圾桶恢复/批量永久删除/清空（二次确认）
- 30 天自动清理
- 笔记列表长按进入批量选择，批量移到垃圾桶
- 聊天归档页批量删除

### 其他
- 状态栏：根背景画到状态栏后，关闭系统对比度强制，只对内容做安全区缩进
- 移除 composer 的假「完全权限」，改为「仅对话」
- 版本号 0.1.2

## 4. 已知缺口

- 电脑 DSH 连接/远端构建：按决定延后
- 项目指令（instructions）还没有编辑入口
- AI 读取笔记仍以显式引用为主，没有项目检索工具/大纲分块
- 版本历史没有 diff 预览，恢复是直接恢复
- 笔记图片附件未接入；聊天附件没有缩略图/相机
- 聊天批量归档只有“归档全部”，没有逐条多选归档
- 单栏混合编辑器还不支持表格、任务列表、代码高亮
- 没有真机/模拟器截图验证；构建与 lint 通过

## 5. 验证

- `./gradlew :app:assembleDebug` 通过
- `./gradlew :app:lintDebug` 通过
- Room 迁移 SQL 在 SQLite 中做了语法验证
- 仍需真机验证：数据库迁移、键盘/输入法、PDFBox、图片视觉请求
