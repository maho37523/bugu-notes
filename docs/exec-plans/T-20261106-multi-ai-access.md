# T-20261106：多厂商 AI 接入方式

日期：2026-11-06。状态：待决定（核心意图已确认，厂商范围与实施授权未确认）。负责人 / 集成人：未认领；本次仅需求整理。

## 原始诉求

> 我想要增加不同厂商ai的适配，其中包括api调用和登录后使用订阅里面的额度，比如gpt和claude这些。

## 现状证据

- 当前 Android 已有按供应商保存配置的 API 调用：`ApiConfigStore` 支持 DeepSeek、OpenAI、阿里云百炼及 OpenAI 兼容自定义地址；聊天使用 OpenAI 风格的流式请求和 SSE 解析。证据：[ApiConfig.kt](../../android/app/src/main/java/com/dspro/android/data/ApiConfig.kt)、[ApiProtocol.kt](../../android/app/src/main/java/com/dspro/android/data/ApiProtocol.kt)、[DeepSeekClient.kt](../../android/app/src/main/java/com/dspro/android/data/DeepSeekClient.kt)、[ApiSettingsScreen.kt](../../android/app/src/main/java/com/dspro/android/ui/ApiSettingsScreen.kt)。
- 当前配置以 API Key、Base URL 和模型为核心；OpenAI 默认地址和模型已配置，但真实供应商/模型兼容性仍待验证。Claude/Anthropic 未见专用适配证据。
- 当前检查范围未发现第三方账号 OAuth 登录、订阅额度鉴权或使用量查询闭环。OpenAI API Key 接入与 ChatGPT/Codex 订阅账号额度是不同接入路径；Claude API 与 Claude 订阅也是不同路径。后两类账号授权能否由第三方 Android 应用使用、允许的授权流程及服务条款尚未查证，不预设可行性。
- Web 原型中的 AI 交互是模拟，不计为 Android 生产能力。见 [产品边界](../product.md)。

## 目标需求（已确认意图，细节待定）

在现有本地 AI 对话中增加多厂商支持，让用户能选择厂商与模型，并明确选择可用的凭据/计费来源。需求包含两类独立路径：

1. **厂商 API 调用**：通过用户配置的官方 API 凭据调用服务；覆盖 OpenAI/GPT 与 Anthropic/Claude，并保留现有 DeepSeek、阿里云百炼及兼容自定义能力。
2. **账号登录及订阅额度（条件目标）**：用户特别说明“订阅”指 Plus、Pro 这类套餐。只有在对应服务商允许第三方客户端使用、并提供适用授权方式时，才支持使用这些订阅套餐额度；如不适用或不允许，应明确说明，不绕过限制。不得把 API 计费误称为订阅额度，也不得将密码收集或非官方凭据抓取作为默认方案。

用户已确认必须支持 API 调用；订阅套餐额度是“合适时”支持的条件目标。目标结果是用户能看清当前厂商、模型与凭据来源，知道请求会使用哪种额度；切换或撤销配置不会串用不同账号/厂商的凭据。具体授权形式、厂商范围与产品文案待决定。

## 范围与排除项

暂定范围：Android 原生聊天请求及其流式响应；供应商、模型与认证来源的选择和状态呈现；连接/鉴权失败反馈；现有聊天持久化行为兼容。

本草案不包含：云端账号体系或自建代理、跨设备同步、模型市场、搜索/语音/后台任务的供应商扩展、未经用户选择的自动路由、多账号共享、订阅额度购买或管理。是否将这些纳入范围需另行确认。

## 验收条件（待确认）

- 每个纳入的厂商均明确标识 API 凭据或订阅账号凭据来源，选择后聊天请求使用对应适配路径。
- API 路径可配置并选择该厂商支持的模型；无效/缺失凭据、网络失败、服务商错误有清楚反馈，不丢失已保存的聊天内容或草稿。
- 订阅账号路径仅在厂商官方授权流程及使用规则允许时提供；登录、取消、过期、撤销和重新授权均有可理解状态，且不会退化为要求用户粘贴密码或抓取网页会话凭据。
- 支持的流式响应、错误响应及必要的停止/重试行为经离线合成回归验证；在线兼容验证仅在另行明确厂商、测试账号/凭据与费用范围后执行。
- 在现有配置升级后，原 DeepSeek/API 配置仍可读取，切换厂商不会覆盖其他厂商配置；已有对话、草稿、项目指令及附件行为不变。
- 未实现或被厂商限制的认证路径明确显示不可用及原因，不以模拟登录或模拟回答表示完成。

## 风险与兼容关注

- 账号订阅与 API 平台计费、额度和模型权限可能不同；用错端点或授权流程会带来额外费用、服务拒绝或违反服务规则的风险。
- OAuth、PKCE、回调 URI、令牌安全存储、刷新/撤销及服务商政策需要逐家核验；不从“有网页登录”推断第三方客户端获准使用订阅额度。
- Anthropic API 的请求格式、SSE 事件和图片/上下文能力不一定兼容现有 OpenAI 风格客户端；适配不能仅替换 Base URL 后就宣称支持。
- 当前 API 配置加密存储在 Keystore 不可用时会回退普通偏好；本需求若新增长期令牌，需单独审查存储与备份边界。现有完整备份排除 API 配置，见 [ADR-0001](../decisions/0001-backup-excludes-api-config.md)。
- API Key/令牌不得写入日志、任务文档或测试夹具；在线请求不在本次整理中执行。
