## 实施

- `python3 tools/check.py quick`：扫描版本范围的文档链接/锚点，检查变更文档空白与 Git 差异，核对 25 项设计哈希，拒绝将私密路径、生成目录或符号链接纳入工程范围。
- `python3 tools/check.py baseline`：先执行 quick，核对已有 JDK/SDK/离线 Gradle，复制当前版本范围文件到全新隔离目录（排除 APK），核对复制前后哈希；运行检查工具自检、构建/Lint及六项回归，记录每项命令、目录、退出码、耗时和日志。
- 每次生成 `.engineering/reports/<时间>/summary.json` 和 inputs.json；失败返回非零，前置失败明确标记后续未执行。工具不启动应用、不安装依赖、不读取 local.properties 或真实数据、不联网调用 API。
- 初始负例自检覆盖断链/错锚、外部文件、空白、篡改/空资产清单、私密路径、缺离线环境、构建失败和跳过套件不能算通过。不是以实现镜像测试代替业务回归。
