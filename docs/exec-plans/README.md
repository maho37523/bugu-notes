只在开始实施某任务时建立独立任务文件并更新本表；不提前制造空任务文档。占用信息不是自动锁，同一工作目录的写入必须串行。没有明确负责人和范围的任务不能开始并行编辑。

## 可复制的任务格式

```markdown
# 任务编号：名称
日期 / 状态 / 负责人：
目标与验收条件：
授权依据；允许和排除范围：
起始基线（Git 或内容校验）；已有修改与保护方式：
占用路径 / 共享行为 / 集成人：
最小实施步骤与风险；需要批准的具体操作：
实际变更文件与原因：
验证（源码基线、目录、环境、命令、结果、证据、限制）：
回退方式（仅本任务，保护后续修改）：
遗留与待决定事项：
交接（下一动作、前置条件、停止写入及进程状态）：
```
