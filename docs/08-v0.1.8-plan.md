# v0.1.8 收敛与可靠性计划

本轮由 GPT-6 Luna 实现，主代理审查并复核最终 APK。

## 第一阶段 · 入口与组织

- 保留顶部笔记/对话和当前范围选择器，项目选择只保留一个主要入口。
- 全局设置集中处理 API、外观、数据、记忆和高级侧栏选项。
- 对象菜单只放当前对象的操作，列表和详情使用相同的重命名、移动、归档、删除行为。
- 默认界面收起模拟任务、插件及无实际实现的分享/朗读入口。
- 统一搜索能找到当前范围的笔记和对话，筛选条件可见，笔记引用复用搜索逻辑。

验收包括笔记与对话都能进入设置、项目切换可发现、对象操作保留、搜索返回后条件一致。

## 第二阶段 · 数据与恢复

- 按会话保存草稿正文、引用、笔记 ID 和附件信息，切换与重启可恢复。
- 流式消息周期保存，停止或切换时保存已收到内容。
- 完整 ZIP 备份覆盖项目、笔记、聊天、版本、记忆、分类、草稿和附件，排除 API Key。
- 恢复前先校验并展示摘要，用户确认后替换，失败时保持数据和附件一致。
- Markdown 导入进入当前范围，支持重复导入时的明确结果反馈。

验收包括草稿不会在发送后复活、数据库迁移保留旧数据、备份可恢复、坏文件被拒绝。

## 第三阶段 · 编辑与 AI 上下文

- 编辑、预览使用共同 Markdown 解释规则，原文保留为导出与保存来源。
- 编辑器增加查找、下一处、上一处、替换当前和全部替换，修改可撤销。
- 发送时记录选中笔记的稳定 ID、标题、实际文本和截取信息。
- 重新生成沿用原请求的引用快照，避免笔记后续修改导致请求悄悄变化。
- 发送前可见引用内容与服务目标，隐私说明准确描述本地保存及远端调用。

验收包括中文/列表/代码/混合格式的源文保留、查找替换撤销、引用按范围隔离与重生成一致。
