# 新功能实施

以项目根 [AGENTS.md](../../../AGENTS.md) 为统一规则入口；开工、版本保存、质量检查和交接遵循其引用规范，本 Skill 只补充功能实施。

1. 读取对应已确认任务及确认依据，核对当前产品规范和代码，识别验收条件与现有行为的差异。缺少需求确认时只整理缺口，按 intake 保存，不能自行确认。
2. 另行核对本次实施授权与 AGENTS 当前阶段是否允许业务变更。需求确认、历史计划和安装本 Skill 都不构成实施授权；阶段尚未开启时保存可审查的最小实施方案与待开启事项，停止业务编辑。已有明确授权不重复询问。
3. 将验收条件映射到最小改动、受影响行为链与测试，先规划再实施。遵循当前架构与兼容边界；新增能力所必需的代码和测试属于本任务，范围外缺陷另记，不顺手重构。
4. 实现功能及与风险相称的测试。按现有质量矩阵执行检查；逐条记录验收证据，将离线技术结果、设备/在线缺口与用户体验验收分开。必要检查不通过时不能声称功能验证完成。

输出已实现行为、验收对应结果及剩余风险。如果目标只是恢复产品既有约定，应使用 bugfix；只检查不实施应使用 review。功能开发中的相关测试和必要修复仍属于 feature，不自动触发其他 Skill。
